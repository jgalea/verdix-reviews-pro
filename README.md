<p align="center"><b>Multi-criteria ratings, visitor ratings and comparison tables for the Verdix Reviews plugin.</b></p>

Verdix Reviews Pro is free while it's in early access.

## What it adds

- Ratings across several criteria, such as features, support and value, rolled up into one score
- Percentage and points scales, plus extra review box styles
- Visitor ratings, which feed a real aggregateRating into the review schema once visitors have rated
- Comparison tables built from your existing reviews, as a block or the `[verdix_compare]` shortcode
- A Draft with AI button that writes first-draft pros, cons and a summary from the post, using the AI provider connected to WordPress 7.0
- Migration from WP Product Review

## Requirements

- [Verdix Reviews](https://wordpress.org/plugins/verdix-reviews/), installed and active
- WordPress 6.0 or later
- PHP 7.4 or later

## Install

1. Download `verdix-pro.zip` from the [latest release](https://github.com/jgalea/verdix-reviews-pro/releases/latest).
2. In WordPress, go to Plugins > Add New > Upload Plugin and upload the zip.
3. Activate it.

New versions show up on the WordPress Updates screen like any other plugin.
